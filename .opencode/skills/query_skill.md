# Query — presentación editorial

Usar la obra seleccionada en `VAULT_PATH` y, en saga, el libro indicado por el `book_scope` autoritativo `Libros/<id>`. Leer su manuscrito, `Libro.md` o `Proyecto.md` y los Markdown pertinentes de planificación, canon y mundo. No usar otro libro ni asumir que existen archivos concretos de una plantilla heredada.

Extraer premisa, conflicto, personajes, tono y elementos distintivos solo de fuentes reales o de información que aporte el usuario. Consultar `get_character`, `get_foreshadowing` y `search_bible` si ayudan, siempre con el scope correcto. Los comparables, la biografía, el destinatario y la extensión requieren datos del usuario o una indicación expresa; no inventarlos.

Preparar la carta o sinopsis en el formato solicitado y marcar claramente los datos pendientes. Evitar revelar giros o desenlaces cuando el encargo lo exija. Una propuesta no modifica el manuscrito ni el canon.
